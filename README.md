# Portfolio

My personal portfolio built with Next.js and TypeScript.

## Development

```bash
npm ci
npm run dev
```

For phone testing, set `NEXT_DEV_ALLOWED_ORIGINS` in an ignored `.env.local`
file to your laptop's Wi-Fi IP address (without a protocol or port), then run:

```bash
npm run dev -- --hostname 0.0.0.0
```

Open `http://<laptop-ip>:3000` on the phone using the same Wi-Fi. Restart the
dev server after changing the address. This setting only affects development.

## Validation

```bash
npm run typecheck
npm test
npm run build
```

## Deployment

The production domain is `https://damian-portfolio.com`. Canonical URLs,
Open Graph URLs, the sitemap, and robots.txt use this domain by default.
Set `NEXT_PUBLIC_SITE_URL` at build time only when deploying to a different
production domain; `.env.example` documents the setting. Preview URLs do not
replace the public production domain in metadata.

Production uses `main`; develop and review changes on `portfolio-v2` before
merging. To preview a production build locally:

```bash
npm run build
npm start
```

Restart `npm start` after rebuilding so its JavaScript and HTML stay in sync.

`next-env.d.ts` is generated by Next.js and is not committed. The typecheck
command generates route types before running TypeScript, including on a fresh
checkout. GitHub Actions runs tests and the production build for pull requests
to `main` and pushes to `main` using Node.js 24.
